# Classic Amiga

Aspect de Kick Off 2 / The Final Whistle (Amiga). Aucune ressource originale n'est fournie : lancez l'importeur
sur votre propre copie du jeu (voir `docs/THEMES.md`). Les images importées vont dans `imported/`, dossier ignoré
par Git.

- `assets.json` : textures attendues dans `imported/`, animations reconstituées et correspondance des états.
- `config/display.json` : 320×256, 13,1234 px/m, image de terrain, ombres. Chaque réglage indique sa provenance.
